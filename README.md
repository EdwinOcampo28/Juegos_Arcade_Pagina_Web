# NEON ARCADE PRO

Abre únicamente index.html con doble clic.

Los archivos de estilos y JavaScript están al lado de la página. La carpeta games contiene los módulos de cada juego. bundle-standalone.js permite abrir la página directamente; app.js, api.js y los demás módulos son la versión separada para editar el proyecto.

No hay credenciales predeterminadas. La primera cuenta creada queda como administradora. La contraseña se guarda como hash SHA-256 y no se puede mostrar en texto. Las cuentas no vienen dentro del ZIP.
